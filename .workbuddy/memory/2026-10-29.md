## 踩坑记录（重要，跨里程碑适用）

1. **PMV2 下纯代码 WinForms 窗体的 DPI 布局坑**（主屏 200% 真机踩过）：
   - GDI 字体随窗口 DPI **自动**放大（9pt 在 200% 屏 = 24px 字形步进），但代码里写的控件/窗体尺寸是物理像素、**不**缩放 → 大字塞进小布局，标签被截断（视觉上像“字符串被截”其实是渲染裁剪）。
   - `AutoScaleMode = Dpi` / `Font` 对纯代码创建的窗体**不生效**（AutoScaleDimensions 手动设 96,96 也没用）。
   - 解法：`AutoScaleMode = None` + 所有布局尺寸统一过 `S(logical) = logical * DeviceDpi / 96`（SettingsForm.cs 已实现）。M1 遮罩/放大镜/工具条照此办理。
   - CJK Label 的 `AutoSize` 测量偏小也会截断 → 用固定宽度 + MiddleLeft。
2. `shot_window.py` 输出的 PNG 是 RGB (colortype 2) 非 RGBA，手写解码按 bpp=3。
3. 排查 UI 截断用「红底诊断 + 像素级测量」（zlib 解 PNG 反过滤 + 扫描线）闭环，别靠猜。
4. WinExe `--selftest` 输出：AttachConsole 在重定向管道下不可靠 → 同时落 `%TEMP%\PlainSnip-selftest.log`（覆盖写）。

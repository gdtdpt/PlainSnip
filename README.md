# PlainSnip

面向 Windows 的极简截图工具：截图 + 贴图（对标 Snipaste 核心体验），后续加入滚动长截图。
自用工具，不做云同步 / 账号 / 插件系统。

## 安装

1. 安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（x64）
2. 拷贝 `PlainSnip.exe` 到任意目录，双击运行——托盘常驻，无主窗口

## 默认热键（可在设置中修改）

| 功能 | 默认热键 |
|---|---|
| 截图 | `F1` |
| 贴图（剪贴板图片钉成置顶悬浮窗） | `F3` |

- 热键被其他程序占用时会在托盘气泡提示，请打开托盘菜单「设置」更换
- 设置保存在 `%APPDATA%\PlainSnip\settings.json`
- 开机自启可在设置中开关（写入 HKCU Run 键，免管理员）

## 常见问题

- **双击后没反应**：PlainSnip 是单实例程序，检查托盘区是否已有图标
- **热键没反应**：确认没被其他截图工具（QQ/微信/Snipaste）占用；可在设置中更换

# PlainSnip

面向 Windows 的极简截图工具：截图 + 贴图（对标 Snipaste 核心体验），后续加入滚动长截图。
自用工具，不做云同步 / 账号 / 插件系统。

## 安装

1. 安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（x64）
2. 拷贝 `PlainSnip.exe` 到任意目录，双击运行——托盘常驻，无主窗口

## 默认热键（可在设置中修改）

| 功能 | 默认热键 |
|---|---|
| 截图 | `F1` |
| 贴图（剪贴板图片钉成置顶悬浮窗） | `F3` |

- 热键被其他程序占用时会在托盘气泡提示，请打开托盘菜单「设置」更换
- 设置保存在 `%APPDATA%\PlainSnip\settings.json`
- 开机自启可在设置中开关（写入 HKCU Run 键，免管理员）

## 当前状态

- 托盘常驻 + 全局热键 + 设置持久化 ✅
- 截图核心 ✅：按 `F1` 进入截图，**悬停自动高亮光标下的窗口/控件，单击即选中**；也可直接拖动自由框选
  - 选区可微调：8 个手柄调整大小、拖动整体移动、方向键 1px 微调（Shift+方向键 10px）
  - 放大镜跟随光标：9x 像素级放大，中心取色显示 RGB/HEX，**点击放大镜复制色值**
  - 完成：工具条「贴图 / 复制 / 保存 / 取消」，或双击选区 / `Enter` 复制；`Esc` / 右键取消
- 贴图 ✅：`F3` 把剪贴板图片钉成置顶悬浮窗（截图工具条「贴图」按钮亦可）
  - 拖动移动；**滚轮缩放**（光标为锚点，25%~400%）；**`Ctrl+滚轮` 调不透明度**（10%~100%）
  - 右键菜单：复制 / 保存为图片 / 缩放 / 不透明度 / 鼠标穿透 / 关闭
  - `Ctrl+C` 复制回剪贴板，`Ctrl+S` 保存，`Esc` / **双击关闭**
  - 鼠标穿透后无法点击贴图，从托盘菜单「贴图列表 → 取消全部穿透」恢复
  - 托盘菜单「贴图列表」可置前各贴图或一键关闭全部
- 规格详见 `PROJECT.md`

## 常见问题

- **双击后没反应**：PlainSnip 是单实例程序，检查托盘区是否已有图标
- **热键没反应**：确认没被其他截图工具（QQ/微信/Snipaste）占用；可在设置中更换

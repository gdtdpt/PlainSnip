# PlainSnip

面向 Windows 的极简截图工具：**截图 + 标注 + 贴图 + 滚动长截图**（核心体验对标 Snipaste / PixPin）。

- 单 exe、免安装、免管理员，托盘常驻无主窗口
- 自用工具，不做云同步 / 账号 / 插件系统 / 录制

## 安装

1. 安装 [.NET 8 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0)（x64）
2. 拷贝 `PlainSnip.exe` 到任意目录，双击运行

## 功能总览

### 截图（`F1`）

- **智能选区**：悬停自动高亮光标下的窗口/控件，单击即选中；也可拖动自由框选
- 选区微调：8 个手柄调整大小、拖动移动、方向键 1px 微调（Shift+方向键 10px）
- **放大镜**：9x 像素级放大，中心取色显示色值（`C` 复制，`Shift` 切换 HEX/RGB）
- 深色工具条 + 悬停气泡提示（含快捷键文案）

### 标注

- 七种工具：矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 / 序号，工具选中后连续使用（粘性）
- 颜色（6 色）× 线宽（细/中/粗）随时切换；画笔笔迹为平滑曲线（基数样条）
- `Ctrl+Z` 撤销 / `Ctrl+Y`（或 `Ctrl+Shift+Z`）重做
- 复制 / 保存 / 贴图均包含已画标注

### 贴图（`F3`）

- 剪贴板图片（或截图工具条「贴图」按钮）钉成置顶悬浮窗
- 拖动移动；**滚轮缩放**（25%~400%，光标锚点）；**Ctrl+滚轮 调不透明度**（10%~100%）
- 右键菜单：复制 / 保存 / 缩放 / 不透明度 / 鼠标穿透 / 关闭
- 托盘菜单「贴图列表」可置前各贴图、取消全部穿透、一键关闭全部

### 滚动长截图

- 截图后按 `L`（或工具条「长截图」按钮）进入，**自己滚轮滚动目标内容**，软件实时截帧拼接（PixPin 式交互）
- 侧边实时预览 + 绿框指示当前画面位置；`A` 自动滚动（光标须在选区内）
- 匹配失败不破坏已拼结果——**往回滚即可续拼**；到底自动提示
- 完成后复制（`Ctrl+C`）/ 保存（`Ctrl+S`）/ 钉成长贴图；`Esc` 退出回普通截图（选区与标注保留）
- 高度上限 16384px；当前仅纵向拼接

## 默认热键（可在设置中修改）

| 功能 | 默认热键 |
|---|---|
| 截图 | `F1` |
| 贴图（剪贴板图片钉成置顶悬浮窗） | `F3` |

- 热键被其他程序占用时会在托盘气泡提示，请打开托盘菜单「设置」更换
- 设置保存在 `%APPDATA%\PlainSnip\settings.json`；开机自启可在设置中开关（HKCU Run，免管理员）

## 常见问题

- **双击后没反应**：PlainSnip 是单实例程序，检查托盘区是否已有图标
- **热键没反应**：确认没被其他截图工具（QQ/微信/Snipaste）占用；可在设置中更换
- **资源管理器里图标是旧的**：Windows 图标缓存按视图分别缓存，刷新（F5）或重建图标缓存即可，exe 内嵌图标以实际提取为准

# v0.1.0（首个公开发布）

发布日期：2026-11-25

## 功能

- **截图**（`F1`）：悬停窗口/控件智能高亮选区、自由框选、8 手柄微调、方向键 1px 微调、放大镜取色（9x，HEX/RGB）
- **标注**：矩形 / 椭圆 / 箭头 / 画笔 / 文字 / 马赛克 / 序号七工具，粘性工具 + 6 色 × 3 线宽，平滑曲线画笔，`Ctrl+Z`/`Ctrl+Y` 撤销重做，标注随复制/保存/贴图合成
- **贴图**（`F3`）：置顶悬浮窗、滚轮缩放（25%~400%）、`Ctrl+滚轮` 不透明度、鼠标穿透、多贴图管理
- **滚动长截图**（`L`）：手动滚动实时拼接（PixPin 式）、侧边预览 + 绿框、`A` 自动滚动、失败回滚续拼、到底自动提示、16384px 高度上限、复制/保存/贴图三去向
- 托盘常驻、全局热键自定义、设置持久化、开机自启（HKCU，免管理员）

## 安装

解压 `PlainSnip-v0.1.0.zip`，双击 `PlainSnip.exe` 即可（self-contained 单文件，无需安装 .NET 运行时）。

## 已知限制

- 滚动长截图仅支持纵向拼接
- 网页内元素级框选需 UIA 增强（v1.5 计划）
- 标注暂不支持选中再编辑（v1.5 计划）
